# Interactive Pie Chart

Ein JavaScript-Projekt mit Vite als Build-Tool.

## Installation

```bash
npm install
```

## Entwicklung starten

```bash
npm run dev
```

## Build für Produktion

```bash
npm run build
```

## Vorschau der Produktion

```bash
npm run preview
```

## Projektstruktur

- `index.html` - Haupt-HTML-Datei
- `src/main.js` - Haupt-JavaScript-Datei
- `src/style.css` - Styling
